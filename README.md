# VibeCoding-Academy · 零基础 AI 编程训练营

面向「会 Excel、没写过程序」的职场同事：8 章跟做式教程，用 Claude Code 把一张销售表变成能点、能筛、能看的网页看板——并学会像开发团队一样用 git 管理它。

- **节奏**：每章 30–60 分钟；7 天训练营节奏（每天 1 章）即可走完，慢一点按 2–3 周也完全够
- **门槛**：会用 Excel 即可。第 0 章带你认识终端、装好 Python / git / Claude Code（含官方订阅与国内端点双路径；版本敏感的安装内容集中在第 0 章，标注最后验证日期）；第 5 章另需一个免费 GitHub 账号（届时注册即可）

## 章节路线

| 章 | 标题 | 内容 |
|---|---|---|
| ch0 | 环境准备：给电脑装上三样法宝 | 认识终端、装 Python、git 和 Claude Code |
| ch1 | 第一次魔法：10 分钟出第一份报告 | 看 AI 把销售表变成网页报告 |
| ch2 | 和 AI 对话的正确姿势 | 背景/任务/要求/验收——「咒语四件套」提示词框架 |
| ch3 | git 时光机：给代码装上存档点 | 像游戏存档一样保存每个版本 |
| ch4 | 从脚本到页面：数据看板 | 升级成能点、能筛、能切换的 Streamlit 交互看板 |
| ch5 | 协作剧场：一个人演完团队协作 | 亲手制造并解决一次真实的合并冲突 |
| ch6 | 开发流程全景 | 需求 → AI 生成 → 审查 → 验证 → 提交 |
| ch7 | 毕业项目：用你自己的数据 | 把真实表格变成实用小工具 |

## 怎么开始

1. 克隆本仓库，双击 `tutorials/index.html` 打开目录页——零构建、零外部依赖，离线可看
2. 按第 0 章装好环境，跑一键自检：

   ```bash
   python example/scripts/check_env.py
   ```

3. 从 ch1 顺序跟做，示例数据在 `example/data/`；每章末尾固定三件套：**动手做**（就地实操）→ **自测 3 题** → **翻车急救箱**

卡住了先翻该章末尾的**翻车急救箱**（收录该章 3–5 种常见报错 + 排查步骤）。跟做中遇到急救箱没覆盖的新报错，欢迎反馈——确认后的典型问题会持续沉淀进对应章节的急救箱。

## 仓库结构

- `tutorials/` — 每章一个独立 HTML（ch0–ch7）+ index.html 目录页
- `example/` — 示例项目参考实现（跟做时自己动手写，这里放的是对账用的参考答案）
- `tools/` — 作者内部工具，不属于教学内容

跟做到某章想确认「标准状态」，可对照章节里程碑 git tag：`ch0-setup`、`ch1-done` … `ch7-done`。
