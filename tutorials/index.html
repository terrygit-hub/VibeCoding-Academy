BEFORE YOU START你需要准备什么

门槛比你想的低

✅ 一台普通电脑（Windows 或 Mac 都行）  ✅ 会用 Excel（懂 VLOOKUP 更好，不懂也行）  ✅ 每天能抽出半小时

❌ 不需要任何编程基础   ❌ 不需要数学   ❌ 不需要英文好（课程全中文，命令照着敲就行）

AI 工具的接入有两条路：官方订阅，或国内可用的模型端点——第 0 章会带你二选一装好。

本课程自身也是用「AI 写代码 + git 管理」的方式开发的——教程怎么教，我们就怎么用。
