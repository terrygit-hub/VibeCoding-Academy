从脚本到页面：数据看板

f2d84a1 · ch4main

report.html 是一张拍好的照片：想换个角度看，就得重新找 AI 再拍一张。这一章把照片变成直播间——你在网页上点一下，全部数字和图表立刻跟着变。

⏱ 约 60 分钟 · 前置：第 3 章

01从「照片」到「直播间」

前三章你已经能指挥 AI 出报告了，但每次都是同一个套路：你提出新问题 → AI 改脚本 → 重新生成 → 你再打开看。报告越多，文件夹里的 html 越堆越多；而你的同事——他们不会用 AI，也不想学——只能在旁边等。

真正的看板是反过来的：把「提问的权利」交给看的人。他想知道华南卖了多少，自己点「华南」；想看 3 月，自己拖月份。你不在线，看板也 24 小时营业。

类比时刻：透视表和切片器

用过 Excel 透视表的人都知道：插入「切片器」之后，点一下「华南」按钮，整张透视表立刻只剩华南的数据。今天要做的看板就是切片器版的销售报告——只不过它是一个网页，老板用手机也能打开，而你要做的主要工作是：把这道菜继续「点」给 AI。

02先装一个新「库」

做交互网页这件事，Python 世界早有人把脏活累活全干完了，打包成一个库，名字叫 Streamlit。库 = 别人写好的功能包，装上就能用——就像手机出厂没有微信，你自己装一个。装库的工具叫 pip，以后你会用它装几十个库：

终端 · 任意目录都可以（装完全局可用）
pip install streamlit
Successfully installed streamlit-…（下载几十兆，耐心等进度条走完）

装库这件事你自己动手，不劳烦 AI——就像给手机装 App 从来不叫秘书代劳。装好之后，写看板的活儿再整个交给它。

03念咒语：四件套点一份看板

老规矩，走到 example 文件夹唤醒 AI（cd example 回车，再 claude 回车）。这次任务变大，四件套一样不少——第 2 章拿到的数据口径直接抄给它，别让它再踩一遍雷：

背景：我在做 data/sales_2024.xlsx 的销售分析（2024 全年 1006 行，列有订单编号、订单日期、地区、城市、产品类别、产品名、销售员、数量、单价、金额）。两个已知问题及口径：① 日期列混有文本格式（如 2024/3/5），统一解析成真日期；② 产品类别有简称混入，「文具」=「办公文具」、「设备」=「办公设备」、「消耗品」=「耗材」，按此统一。
任务：用 Streamlit 做一个交互看板 dashboard.py：左侧筛选器（地区多选、月份范围、产品类别多选），主区域放三个指标卡（总销售额、订单数、平均订单额）、月度走势条形图、按地区和按类别的汇总条形图、销售员排行表，全部随筛选联动。
要求：全中文界面，数字带千分位，图表统一用橙色 #E8630A 单色，风格干净不花哨。
验收：启动看板，自己逐个点筛选器确认联动正常、数字对得上，再交给我。

好的，正在创建 dashboard.py：读取 Excel → 按口径清洗日期和类别 → 搭建侧边栏筛选器 → 指标卡与图表联动……已完成自测，看板启动正常，请验收。

（浏览器通常会自动弹出；没弹就自己开一个，地址栏输 localhost:8501）

localhost 是个啥？

地址栏里的 localhost:8501 意思是「本机上的 8501 号端口」——AI 的小程序在你电脑上开了一扇门，浏览器从这扇门进出。只有这台电脑能看，外人访问不到，所以放心大胆地玩。终端窗口别关：它是这个网站的发动机；想让网站下班，回到终端按 Ctrl+C。

04验收：亲手点一遍

AI 说「已完成自测」不算数，你的眼睛过一遍才算验收。成品长这样：

验收动作只有三个：① 地区只选「华南」——三个大数字和所有图表应立刻变小；② 月份拖成「3 月到 3 月」——月度走势只剩一根柱子；③ 全部恢复默认——数字回到全量。每点一下，背后都是整个脚本从头重跑一遍：1000 行数据，眨眼间的事。这就是它「活」的原因。

05第三颗雷：筛选器是照妖镜

第 2 章埋下的五颗雷，你已亲手排掉两颗。这一章会撞上第三颗——而且大概率是在你点筛选器的时候自己看见的：地区多选框里混进来一个奇怪的名字 nan（= 没填）。奇怪的地方在于：第 2 章按月、按类别汇总时它都没露面。

原因很简单：汇总可以不点名，筛选必须点名。「按月份汇总」不碰地区列，空着无所谓；「按地区筛选」要列出所有地区名，空格子瞬间现形——筛选器是照妖镜。

看见了就轮到你拍板（AI 没法替你决定业务口径）：这 12 笔没填地区的订单，删掉还是标出来？我们的口径：不删，归成「未填写」，让看板把这件事写在明处：

地区筛选里出现了 nan——查一下是没填地区的订单，大概 12 笔。口径：不要删掉，把空的地区统一写成「未填写」（城市同理），并在看板页面顶部用一行小字说明「其中 N 笔订单地区未填写」。

查实：共 12 笔订单地区为空。已统一归入「未填写」（城市同步处理），页面顶部已加说明。现在地区筛选里是「未填写」而不是 nan，全选订单数仍是 1,006 笔——数据一笔没丢。

口径是你定的，活是它干的

注意这次对话的分工：发现异常（你的眼睛）、判断怎么处理（你的业务）、执行修改（它的手）。缺失、重复、金额对不上……真实数据里这类问题永远修不完，重要的不是修，而是「知道它在哪、有多少、怎么处理的」。第 6 章我们会把这个意识升级成一套系统的「数据体检」。

自测 3 题（点击展开答案）

1. 「库」是什么？装一个库的命令长什么样？

库 = 别人写好的功能包，装上就能用，就像给手机装 App。命令：pip install 库名。本章装的 Streamlit 专门用来把 Python 变成交互网页。

2. 看板和第 1 章的报告，最本质的区别是什么？

报告是「照片」：生成那一刻就定格了，想换角度得重新生成；看板是「直播间」：把提问的权利交给看的人，点一下筛选器，整个脚本实时重跑一遍。一个服务于「这一次的结论」，一个服务于「以后每一次的好奇」。

3. 为什么「地区没填」这颗雷第 2 章没炸、第 4 章才炸？

第 2 章做的是汇总（按月、按类别），不碰地区列，空值藏得住；第 4 章做的是筛选，必须把地区列的每个值列出来点名，空格子当场现形。同一段脏数据，不同用法炸不同的雷——所以体检（第 6 章）要主动排查，不能等它炸。

翻车急救箱

① pip install 卡在下载不动 / 超时
网络问题，换国内镜像再装：pip install streamlit -i https://pypi.tuna.tsinghua.edu.cn/simple。

② 'streamlit' 不是内部或外部命令
装好了但终端找不到它。用这种方式启动（效果完全一样）：python -m streamlit run dashboard.py。

③ 浏览器没自动打开 / 打不开 localhost:8501
先确认启动看板的终端还开着（它是发动机）。然后自己开浏览器，地址栏输入 localhost:8501 回车。还不行，看终端里打印的 Local URL 照抄。

④ 改了代码，页面没变化
看板不会自己刷新：保存代码后回到浏览器，点页面右上角的 Rerun（或直接 F5）。

⑤ Port 8501 is already in use
上一次的看板还开着没关。找到旧终端按 Ctrl+C 关掉再启动；或者换个端口启动：python -m streamlit run dashboard.py --server.port 8502（浏览器访问 localhost:8502）。
