第一次魔法：10 分钟出第一份报告

c41a9f7 · ch1main

这一章你一句代码都不用写。你只负责说清楚想要什么，剩下的交给 AI。十分钟后，一张销售表会变成一份能发给你老板的网页报告。

⏱ 约 30 分钟 · 前置：第 0 章自检全绿

01十分钟后你会有什么

你手里有一张 100 行的销售流水表 sales_simple.csv。十分钟后，它会变成这样一份报告——不用 Excel 透视表，不用函数，你只需要「下一个单」：

类比时刻：点外卖

用 AI 写代码就像点外卖：你在手机上说清楚想吃什么（需求），厨房（AI）负责炒菜（写代码、跑程序），半小时后餐送到桌上（生成 report.html）。你不需要会炒菜，但你得会点菜——说「随便来点吃的」的人，往往收到不该放香菜的香菜牛肉面。

02第一步：看一眼原材料

先用 Excel 双击打开 example\data\sales_simple.csv，你会发现它比一般流水表还友好——每列都是规整的：

列名是什么例子
订单编号每笔订单的唯一代号SO-2025-0001
订单日期下单日期（2025 年 7–9 月）2025-07-29
地区 / 城市客户所在区域华北 / 北京
产品类别 / 产品名卖的是什么耗材 / 硒鼓
销售员谁卖的李婷
数量 / 单价 / 金额金额 = 数量 × 单价4 × 320 = 1280

看懂了吗？接下来你要让 AI 告诉你：哪个地区卖得最多、哪类产品最赚钱、谁是销冠。

03第二步：走到工作台，唤醒 AI

打开终端（第 0 章我们已经成为朋友了），「走到」示例项目所在的文件夹，然后把 AI 叫醒：

终端（在课程仓库根目录下）
# 「走到」example 文件夹——就像在文件管理器里双击进入这个文件夹
cd example
# 唤醒 AI 助手（第 0 章装好的那个）
claude
✓ Welcome to Claude Code.  (初次进入会显示一些提示，直接按回车继续即可)

现在你的终端变成了一个对话窗口：光标在闪，等你说第一句话。想退出时输入 /exit 回车即可。

04第三步：念出第一段咒语

在 AI 对话框里，把下面这段话原样输入（也可以按你的意思改，改了更有意思）：

请帮我分析 data/sales_simple.csv（注意是 UTF-8 带 BOM 编码）。统计：总销售额、订单数、平均订单额，并按「地区」和「产品类别」分别汇总销售额。把结果生成一个独立可打开的网页报告 report.html：数字带千分位，汇总用横向条形图，风格明亮简洁。写完脚本请运行它，确认报告生成成功。

按下回车，见证时刻到了——AI 会自己创建文件、自己敲命令、自己检查结果：

好的，我来创建分析脚本 ch1_report.py：读取 CSV → 计算汇总 → 生成网页报告……

✓ 报告已生成：report.html
总销售额 ¥121,174 · 共 100 笔订单

AI 在终端里的一连串操作不用全看懂，刚才只发生了三件事：

黄金法则：报错别慌，原样发给它

如果 AI 的输出里出现了大段红色报错——恭喜，这是最好的教材。把报错完整复制，发给 AI：「运行报了这个错，帮我修复」。它修好会自己重跑。这条法则能解决你今后 90% 的问题。

05第四步：验收成果

在文件管理器里打开 example 文件夹，找到 report.html，双击——浏览器会打开你的报告。三个大数字、两组条形图、一张销冠排行表，全部来自你那张 CSV。

心态校准：你不需要看懂代码

打开 ch1_report.py 你大概率一个字都看不懂——这完全正常，也完全不碍事。就像开车不需要懂发动机。你现在掌握的是「说清需求 → 验收结果」，这是 vibe coding 的核心技能；代码细节，等你想懂的时候再让 AI 逐行讲解（第 2 章教你最好用的问法）。

06第五步：改需求——魔法的精髓

真正的魔法不是「一次成功」，而是随时可以改。回到 AI 对话框（没退出的直接继续说；退出了就在 example 目录再敲一次 claude，并用 /resume 或直接说明接着上次的 report 继续）：

报告很好！再帮我加一个「按月份」的销售额汇总，放到地区图下面。

好的，我来修改 ch1_report.py：按订单日期提取月份汇总……已完成，请刷新浏览器里的 report.html 查看。

刷新浏览器（F5）——报告长出了新图表。这就是迭代：小步提需求、小步看结果，永远不要一次提出十个要求。

07课后三件套

动手做：城市 Top 5

让报告再增加一块「销售额 Top 5 城市」条形图。提示：数据里已经有「城市」这一列了。

点开看参考过程

请在报告里增加「销售额 Top 5 城市」的横向条形图，按销售额从高到低排列。

好的：按「城市」汇总金额、取前 5 名、倒序排列，插入到销售员排行表之前……已生成，请刷新查看。

如果 AI 的结果顺序不对（从低到高了），直接说「顺序反了，改成从高到低」——提修改意见也是迭代的一部分。

自测 3 题（点击展开答案）

1. 这一章我们「写」的代码，到底是什么？

一段保存在 ch1_report.py 里的 Python 脚本——只是它由 AI 代笔。它留在你的文件夹里，是可以反复运行的「菜谱」，不是一次性的魔法。

2. 为什么 report.html 双击就能看，别的同事没装 Python 也能看？

因为 HTML 是全世界浏览器都认的「网页标准格式」。Python 只在生成报告时用到；生成之后，report.html 是完全独立的成品。

3. 想让报告再多一个统计维度，正确做法是？

回到 AI 对话框继续提需求（迭代），而不是自己动手改代码、也不是从头重来。小步提、小步看。

翻车急救箱

① FileNotFoundError：找不到 sales_simple.csv
说明 AI 在错误的文件夹里找文件。对它说：「检查当前目录和文件路径」，并确认你的终端确实在 example 目录里（提示符看得见路径，或敲 cd 看看跳到哪）。

② ModuleNotFoundError: No module named 'pandas'
缺数据分析库。退出 AI（/exit）后在终端运行 pip install pandas，装完回来让 AI 重跑。

③ KeyError: '﻿订单编号'（列名报错）
文件开头的 BOM 标记被读进了列名。对 AI 说：「读取时请加 encoding='utf-8-sig'」。

④ UnicodeEncodeError: 'gbk' codec…
Windows 终端打印 ¥ 符号的老毛病。对 AI 说：「在脚本开头把输出编码切换为 UTF-8」。它会加一行 sys.stdout.reconfigure(encoding="utf-8")。

⑤ 双击 report.html 打开是乱码或记事本
右键文件 → 打开方式 → 选择浏览器（Edge/Chrome）。报告本身没有坏。
