环境准备：给电脑装上三样法宝

a07e3d1 · ch0main

这一章一行代码都不写。我们只做一件事：把后面 7 章要用的三样工具装好，并和「终端」交个朋友。装完跑一个自检脚本，全绿就毕业。

⏱ 约 45 分钟 · 无前置要求 · 本章安装步骤最后验证日期：2026-08

01要装什么，为什么是它们

开车之前得有车、有钥匙、有导航。这门课的三样法宝对应关系是：

法宝是什么在本课里干嘛
🚌 Python跑数据的引擎真正执行分析的「发动机」
🕰 Git代码的时光机保存/回退每个版本，团队协作（第 3、5 章主角）
🤖 Claude Code你的 AI 程序员你说话，它写代码

另外还有一位不用安装的朋友——终端，它已经在你电脑里了，我们从它开始。

02认识终端：和电脑打字聊天的窗口

类比时刻：微信聊天框

终端就是一个只有文字的聊天窗口，聊天对象是你的电脑。平时你点图标、按菜单是在「比划」，而在终端里，你直接「打字告诉它做什么」。它响应快、能做的事多——是程序员和 AI 助手的主要工作地点。它不会因为敲错一个字就爆炸，大不了关掉重开。

打开它

Windows：按 Win 键 → 输入 powershell → 回车。弹出的蓝底（或黑底）窗口就是终端。
macOS：Command+空格 → 输入 终端 或 Terminal → 回车。

来，发出你人生第一条终端命令——问电脑「我是谁」：

终端 · 你输入 whoami 后回车
whoami
desktop-a1b2c3\xiaoming

电脑回答了你的用户名。刚才发生的事情拆开看：

以后每章你都会用这个窗口。不用记命令——命令永远可以回来抄。

03法宝一：Python（跑数据的引擎）

安装

浏览器打开 python.org/downloads，下载最新的 Python 3 安装包（Windows 点黄色大按钮；macOS 建议直接用系统自带的 Python 或同样从此页下载）。

Windows 最重要的一步

安装第一屏，务必勾选底部的「Add python.exe to PATH」，再点 Install Now。这一步决定了终端能不能「找到」Python——每年最多的翻车都在这。

验证 + 装两个数据工具箱

装完后关掉终端，重新打开一个新的（重要！老终端不认识新装的软件），然后：

终端 · 验证 Python 并安装 pandas、openpyxl
python --version
Python 3.13.5
# pip 是 Python 的「应用商店」，装后面要用的两个数据分析库
pip install pandas openpyxl
Successfully installed pandas-2.x.x openpyxl-3.x.x ...

版本号 3.10 以上都算合格。看到 Successfully installed 就成了。

04法宝二：Git（代码的时光机）

浏览器打开 git-scm.com/downloads/win，下载 Windows 版安装包。一路点「Next」用默认选项即可——那些选项是给老手准备的，默认值对我们都合适。macOS 用户在终端输入 git --version，系统会自动引导安装。

装完同样重开终端验证：

终端 · 验证 git
git --version
git version 2.52.0.windows.1

附带一个好消息：装了 Git，你的 AI 助手在 Windows 上也能工作得更好（它内置的很多操作依赖 git 工具）。现在不急着学它怎么用——第 3 章专门讲。

05法宝三：Claude Code（你的 AI 程序员）

在 PowerShell 终端里运行官方推荐的原生安装命令（一行，回车后等它跑完）：

PowerShell · 安装 Claude Code（macOS 用：curl -fsSL https://claude.ai/install.sh | bash）
irm https://claude.ai/install.ps1 | iex
Claude Code installed successfully!

重开终端，验证：

终端 · 验证
claude --version
2.1.211 (Claude Code)
# 觉得不对劲时可随时运行「体检」命令：
claude doctor

装好了，还差最后一步——让 AI 知道「你是谁、走哪个门进来」。下面两条路二选一：

路径 A：官方订阅（有 Claude Pro/Max 账号）

终端里直接输入 claude 回车，它会让你在浏览器里登录你的 claude.ai 账号，跟着点完即可回来。（注意：免费版 claude.ai 账号不含 Claude Code，需要 Pro 或 Max 订阅。）

路径 B：国内模型端点（没有海外订阅）

Claude Code 支持把请求转发到任何 Anthropic 兼容的服务端点。国内的模型服务商（如智谱、DeepSeek 等）大多提供这种接入方式，去你选定的服务商控制台开通一个 API Key，然后配置一个文件：

按 Win+R，输入 notepad %USERPROFILE%\.claude\settings.json 回车（macOS 用 nano ~/.claude/settings.json），粘贴以下内容并保存（记事本会问是否新建文件，选「是」）：

settings.json · 端点与密钥（占位内容以你的服务商文档为准）
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://你的服务商端点地址",
    "ANTHROPIC_AUTH_TOKEN": "你的API密钥"
  }
}
  • ANTHROPIC_BASE_URL：告诉 Claude Code 把请求发到哪个服务地址
  • ANTHROPIC_AUTH_TOKEN：你的身份凭证，服务商用它认出你（部分服务商要求用 ANTHROPIC_API_KEY 这个名字，看它的接入文档）

保存后在终端运行 claude doctor，没有红色报错就配置成功。这个文件就是 AI 助手的「工牌」，以后不用再动它。

06拿到教材：你的第一次 git 操作

现在用刚装好的 git，把这门课的完整材料（教程 + 示例数据）从 GitHub 复制到你的电脑。在终端里：

终端 · 克隆课程仓库（地址以课程发布页为准）
# 先「走到」桌面，材料会下载到那里
cd Desktop
git clone https://github.com/课程方/vibe-coding-academy.git
Cloning into 'vibe-coding-academy'...
done.
cd vibe-coding-academy

恭喜——你刚刚完成了人生第一次 git 操作（clone，克隆）：把云端一个完整项目连同它的全部历史复制到了本地。原理先不管，第 3 章会回头解释。现在你只需要知道：桌面上多了个文件夹，里面是全部课程材料。

连不上 GitHub？多试两次、换个时间段，或直接在仓库页面点绿色 Code 按钮 → Download ZIP，解压到桌面同样能用。

自测 3 题（点击展开答案）

1. 为什么每次装完软件都要「关闭终端，重新打开」？

终端在启动时记住一份「软件位置清单」（PATH 环境变量）。新装的软件登记进了清单，但已经开着的终端还在用旧清单，找不到它。重开 = 重新读清单。

2. 路径 B 里的 ANTHROPIC_BASE_URL 是干什么的？

它告诉 Claude Code「把请求发到哪个服务地址」。不设置时默认发到官方；填上国内服务商的端点地址后，就走你开通的那条路。配好之后日常使用和路径 A 没有区别。

3. git clone 刚才到底做了什么？

把云端（GitHub）上的一个完整项目——所有文件、所有文件夹、连同它的全部修改历史——原样复制了一份到你的电脑。从此你在本地怎么折腾都不影响云端原件。

翻车急救箱

① 'python' 不是内部或外部命令……
两个可能：装的时候没勾「Add python.exe to PATH」，或者没重开终端。先重开终端再试；还报错就重新运行安装包，勾上那一项再装一遍。

② 敲 python 却弹出了 Microsoft Store
Windows 的「应用执行别名」在捣乱。设置 → 应用 → 高级应用设置 → 应用执行别名，把 python.exe 和 python3.exe 两个开关关掉，重开终端。

③ 'claude' 不是内部或外部命令 / 'irm' 不是内部命令
前者：重开终端再试。后者：你在 CMD 里跑了 PowerShell 命令——开一个 PowerShell 窗口（Win 键搜 powershell）再运行；或改用 CMD 版命令 curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd。

④ pip install 下载极慢或超时
用国内镜像：pip install pandas openpyxl -i https://pypi.tuna.tsinghua.edu.cn/simple

⑤ git clone 超时 / 连不上 GitHub
国内网络常见。多试几次、换时段；或仓库页面 Code → Download ZIP 解压使用，不影响学习。

⑥ claude doctor 提示 settings.json 有错
九成是 JSON 语法：漏了引号、多了逗号、用了中文引号。对照本章模板逐字检查，改完保存，再跑一次 claude doctor。
